Technical details

Refresh rate and resolution come from SurfaceFlinger; link values from the kernel at the last (re)connect.

Frames per second = frames sent to the monitor; lower when nothing moves.

Link utilisation = pixel clock × bits per pixel of the 17.28 Gbit/s link (HBR2 × 4).

Phone power = fuel gauge system current × voltage, whole phone.
